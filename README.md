A deterministic Python chess engine that plays the make.fun gauntlet in under 4 KB. It uses bitboards, iterative deepening, and a tapered evaluation.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8000 python3 main.py
```
